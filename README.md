# QuickAd AI

Turn product photos into ready-to-post vertical promotional videos.

## Version 1 workflow

Upload images → Describe product → Choose style → Create video

## Version 1 output

- 20–30 second promotional video
- Vertical 9:16 MP4
- AI narration
- Captions
- Background music
- Product logo
- Website and call to action

## Product rule

If a new user needs instructions to create their first video, the product is too complicated.
